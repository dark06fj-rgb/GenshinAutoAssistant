# Contributing translations

Before adding an entry:

- Confirm the exact source wording and context.
- Reuse an existing glossary term where applicable.
- Keep source IDs and placeholders unchanged.
- Add provenance and game-version information when available.
- Use `draft` until another person has reviewed the Arabic.
- Do not claim that an entry is official.

For longer strings, include a short context note (menu, item description, quest dialogue, tutorial, etc.). Avoid machine-translated text being marked as reviewed without human checking.
